Python Loop Practice

A collection of beginner-to-intermediate practice exercises focused on Python loops — for loops, while loops, nested loops, and loop control statements (break, continue, else).

📌 About

This repository contains simple, self-contained Python scripts written while practicing looping concepts and control flow in Python.

🧠 Topics Covered


Basic for loops (iterating over ranges, lists, strings)
while loops and loop conditions
Nested loops (patterns, multiplication tables, grids)
Loop control statements: break, continue
for...else and while...else
Common loop-based problems (sum, factorial, prime check, pattern printing, number reversal, etc.)
